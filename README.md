# AI-Powered Network Congestion Prediction 🚀  

## 📌 Project Overview  
This project simulates network congestion using **ns-3** and predicts congestion levels using **AI (Machine Learning in Python).**  

- **📡 Simulates a 5-node network** (Normal vs. Congested Traffic)  
- **📊 Collects network performance metrics** (Latency, Packet Loss, Throughput)  
- **🧠 Uses AI to predict congestion** based on real-time network conditions  

---

## 🛠️ Technologies Used  
- **ns-3** (Network Simulation)  
- **C++** (Traffic generation & monitoring)  
- **Python (Machine Learning)** (AI Congestion Detection)  
- **GitHub** (Code hosting & version control)
